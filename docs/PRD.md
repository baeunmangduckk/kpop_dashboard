# K-POP 산업 인사이트 대시보드 v3 MVP PRD

## 🎯 핵심 정보

**목적**: 출처와 신뢰도가 섞인 K-pop 산업 지표를 투명하게 보여주고, 3대 서사(최고 실적 속 둔화 신호 / 판매 분산과 자본 집중 / 지역 재편과 AI·버추얼)로 묶어 산업 흐름을 이해할 수 있게 한다.
**사용자**: 정확한 수치와 출처가 필요한 산업 분석가·기획사/투자 관계자·팬덤 마케터와, 핵심 메시지만 빠르게 보려는 일반 독자 (로그인 없이 공개 열람)

## 🚶 사용자 여정

```
1. 홈(스토리)
   ↓ 핵심 KPI 6종과 서사 카드 3종 확인

   [서사 카드 클릭] → 서사 상세(①/②/③) → 근거 지표 링크 클릭 → 해당 지표 페이지
   [KPI 카드 클릭]  → 해당 지표 페이지(시장 전망·판매 집중도·기획사 재무 등)
   [헤더 지표 메뉴] → 지표 페이지 직접 이동
   ↓

2. 지표 페이지
   ↓ 차트·표 확인, 필터(회사·연도·키워드) 조작
   ↓ 신뢰도 배지 / 출처 표기 클릭

3. 출처·신뢰도 페이지
   ↓ 출처별 사용 지표, 신뢰도 분포, 알려진 불일치 확인

4. 완료 → 관련 지표 페이지로 돌아가기 또는 홈으로 이동
```

| **다음 이동**   | 출처 표기 → 출처·신뢰도 페이지                                                                                                                 |

### 출처·신뢰도 페이지

> **구현 기능:** `F011` | **메뉴 위치:** 헤더 출처·신뢰도

| 항목            | 내용                                                                                                                                                                                                                        |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **역할**        | 모든 지표의 출처와 검증 상태 공개                                                                                                                                                                                           |
| **진입 경로**   | 헤더 메뉴, 각 페이지의 신뢰도 배지·출처 표기 클릭, 홈 신뢰도 요약                                                                                                                                                           |
| **사용자 행동** | 출처를 검색·필터하고 사용 지표와 불일치 내역을 확인                                                                                                                                                                         |
| **주요 기능**   | • 출처 레지스트리 표(발행처·제목·연도·사용 페이지) + 페이지·신뢰도 필터<br>• 출처별 사용 지표 목록<br>• 신뢰도 라벨 분포 차트와 라벨 정의 설명<br>• 알려진 불일치 목록(예: 하이브 2025 영업이익 DART 493.2억 vs 보도 499억) |
| **다음 이동**   | 사용 지표 클릭 → 해당 지표 페이지                                                                                                                                                                                           |

## 🗄️ 데이터 모델

> 모든 데이터는 `public/data/*.json` 정적 산출물이며 Zod 스키마(`src/lib/schemas/`)로 검증한다.

### Metric (지표)

| 필드       | 설명                      | 타입/관계                           |
| ---------- | ------------------------- | ----------------------------------- |
| id         | 고유 식별자               | string                              |
| label      | 지표명                    | string                              |
| value      | 값 (결측은 null)          | number \| null                      |
| unit       | 단위                      | string                              |
| delta      | 전기 대비 증감            | number \| null                      |
| confidence | 신뢰도 라벨               | verified \| estimated \| unverified |
| sourceIds  | 출처 목록 (1개 이상 필수) | → Source.id[]                       |
| asOf       | 기준일 (선택)             | date                                |
| method     | 추정 산출 방식 (선택)     | string                              |

### Narrative (서사)

| 필드     | 설명                  | 타입/관계                               |
| -------- | --------------------- | --------------------------------------- |
| id       | 서사 slug(①~③)        | slowdown \| polarization \| realignment |
| title    | 제목                  | string                                  |
| message  | 핵심 메시지           | string                                  |
| sections | 문단 + 근거 지표 묶음 | → Metric.id[]                           |

### Insight (인사이트)

| 필드      | 설명           | 타입/관계                   |
| --------- | -------------- | --------------------------- |
| id        | 고유 식별자    | string                      |
| kind      | 자동/수동      | auto \| manual              |
| tone      | 주의/참고/긍정 | warning \| info \| positive |
| text      | 본문           | string                      |
| metricIds | 관련 지표      | → Metric.id[]               |

### Source (출처)

| 필드      | 설명             | 타입/관계 |
| --------- | ---------------- | --------- |
| id        | 고유 식별자      | string    |
| publisher | 발행처           | string    |
| title     | 제목             | string    |
| year      | 연도             | number    |

| pages     | 사용 페이지      | string[]  |

### CompanyFinancial (기획사 재무)

| 필드            | 설명            | 타입/관계                           |
| --------------- | --------------- | ----------------------------------- |
| company         | 회사명          | string                              |
| year            | 회계연도        | number                              |

| operatingProfit | 영업이익(억원)  | number \| null                      |
| confidence      | 신뢰도 라벨     | verified \| estimated \| unverified |
| sourceIds       | 출처 (1개 이상) | → Source.id[]                       |

### AlbumSales (앨범 판매)

| 필드        | 설명   | 타입/관계 |
| ----------- | ------ | --------- |

| album       | 앨범명 | string    |

| ----------- | ----------------------- | -------------- |

| 필드        | 설명           | 타입/관계                       |
| ----------- | -------------- | ------------------------------- |

| adopted     | 채택 값과 출처 | { value, sourceId → Source.id } |

| note        | 설명           | string                          |

### 데이터 파일 구성

| 파일                                    | 내용                                                                                                         |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `metrics.json`                          | 전체 Metric 레지스트리 + 홈 KPI 6종 순서(`homeKpiIds`)                                                       |
| `insights.json`, `narratives.json`      | Insight[], Narrative[]                                                                                       |
| `sources.json`, `discrepancies.json`    | Source[] (출처 레지스트리), Discrepancy[] (알려진 불일치)                                                    |
| `market.json` ~ `ai-virtual.json` (6종) | 페이지별 묶음: 핵심 지표 `metricIds` + 차트·표 블록. 블록마다 `confidence`·`sourceIds`(1개 이상)를 함께 보관 |

- 스키마: `src/lib/schemas/` (모델), `src/lib/schemas/datasets/` (파일 단위)
- 로더: `src/lib/data/` — 서버에서 읽고 Zod 검증, 실패 시 파일명·필드 경로가 담긴 `DataLoadError`
- 무결성 검증: `npm run validate:data` (`scripts/validate-data.ts`, `check-all`에 포함) — 라벨 부착률·출처 연결률 100%, 미정의 참조·라우트·중복 id 탐지
- 캐시: 정적 페이지는 빌드 시 1회 읽으므로 JSON 갱신 후 재빌드 필요 (개발 서버는 요청마다 반영)
